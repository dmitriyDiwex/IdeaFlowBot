# Telegram-панель

Этот файл объясняет, как пользоваться новой кнопочной панелью в главном боте.

## Где открыть панель

1. Открой главного бота.
2. Напиши команду `/panel`.
3. Если твой Telegram id есть в `GENERAL_ADMIN` или в списке модераторов, бот покажет кнопки управления.

## Что означают кнопки

### `Обновить входящие`

Эта кнопка запускает импорт из старого collector-слоя.

Что происходит:

- старый саббот уже сохранил сообщение в legacy SQLite;
- importer переносит новые записи в таблицу `submissions`;
- после этого сообщение появляется в новой editorial-панели.

Если бот пишет `Импортировано: 0`, это не ошибка. Это значит, что новых записей с прошлого импорта нет.

### `Поступившие сообщения`

Это очередь новых сообщений, которые еще не прошли первую модерацию.

Проще говоря:

- сюда попадает свежая предложка;
- здесь модератор решает, что делать с сообщением дальше.

Доступные действия:

- `Approve` — создать из сообщения `content_item` и одобрить его;
- `Publish now` — сразу отправить сообщение в publish pipeline;
- `Save as paste` — сохранить сообщение в библиотеку паст;
- `Hold` — временно отложить сообщение;
- `Reject` — отклонить сообщение.

### `Все сообщения`

Это журнал всех `submissions`, которые уже лежат в новой базе.

Здесь видны не только новые сообщения, но и уже обработанные:

- новые;
- отложенные в `hold`;
- превращенные в `content_item`;
- отклоненные;
- отмеченные как пасты.

Если нужно просто просмотреть базу входящих сообщений, открывай именно этот раздел.

### `Черновики на review`

Это не сырые входящие сообщения, а уже собранные черновики постов.

Сюда попадает контент, который уже существует как `content_item`:

- из реального `submission`;
- из пасты;
- из генерации;
- из ручного редакторского создания.

Разница простая:

- `Поступившие сообщения` — сырые входящие;
- `Черновики на review` — почти готовые посты, которые ждут финального решения.

### `Пасты`

Это библиотека паст из таблицы `paste_library`.

Через этот раздел модератор может:

- просматривать все пасты, которые уже лежат в базе;
- добавлять новую пасту вручную;
- вручную добавлять и убирать теги у пасты;
- пересчитывать auto-теги пасты;
- выбирать основной тег пасты;
- убирать пасту из активной работы кнопкой удаления.

Важно:

- кнопка удаления не стирает пасту навсегда;
- сейчас паста переводится в статус `archived`.

Как добавить пасту вручную:

1. Открой `Пасты`.
2. Нажми `Добавить пасту`.
3. Отправь текст одним сообщением.

Если нужен свой заголовок, отправь сообщение в формате:

`Заголовок :: Текст пасты`

### `Теги`

Это словарь тегов и ключевых слов.

Через этот раздел можно:

- добавить новый тег;
- включить или выключить тег;
- добавить ключевые слова;
- выключить отдельное ключевое слово.

Новый тег добавляется строкой:

`slug :: Название`

Например:

`summer :: Лето`

Ключевые слова можно отправлять через запятую:

`лето, каникулы, июль`

Внутри раздела `Теги` есть кнопка `Массовые правила паст`.

Она управляет правилами, которые применяются сразу ко всем каналам:

- `Поставить Include для всех` — все каналы временно или постоянно берут только пасты с указанным тегом;
- `Убрать Include для всех` — удаляет глобальный include для указанного тега;
- `Поставить Exclude для всех` — запрещает пасты с указанным тегом во всех каналах;
- `Убрать Exclude для всех` — удаляет глобальный запрет.

Можно поставить правило без срока:

`summer`

Или со сроком действия:

`summer до 2026-08-31`

`summer 31.08.2026 23:59`

Глобальный include и include конкретного канала работают как два отдельных фильтра. Например, если глобально включён `summer`, а у канала включён `art`, паста должна иметь подходящий глобальный тег и подходящий канальный тег. Exclude всегда сильнее include.

### `Каналы и слоты`

Здесь показывается список каналов из editorial-слоя.

После выбора канала можно:

- посмотреть все временные слоты публикации;
- добавить новый слот;
- удалить конкретный слот;
- быстро создать стандартный набор слотов.
- настроить теги паст, которые можно или нельзя публиковать.

В `Теги паст` у канала есть два списка:

- `Только с тегами` — если список не пустой, scheduler берёт только пасты с одним из этих тегов;
- `Запрещённые теги` — пасты с этими тегами не берутся.

Запрет сильнее разрешения. Если паста одновременно `summer` и `tech`, а у канала включено `Только summer` и `Запрещён tech`, такая паста не пройдёт.

Как добавить слот:

1. Открой канал.
2. Нажми `Добавить слот`.
3. Отправь сообщение в одном из форматов:

- `10:00` — слот на все дни;
- `all 10:00` — то же самое;
- `0 09:30` — слот только на понедельник;
- `0,2,4 18:00` — слот на понедельник, среду и пятницу.

Где дни недели:

- `0` — понедельник
- `1` — вторник
- `2` — среда
- `3` — четверг
- `4` — пятница
- `5` — суббота
- `6` — воскресенье

### `Запустить scheduler`

Кнопка вручную запускает планировщик.

Он:

- смотрит на слоты;
- ищет подходящий одобренный контент;
- создает записи на публикацию.

### `Запустить publisher`

Кнопка вручную запускает отправку уже запланированных публикаций в Telegram-каналы.

## Кнопки генерального админа

Эти кнопки доступны только пользователю из `GENERAL_ADMIN`.

### `Сабботы`

Позволяет:

- добавить саббота;
- удалить саббота.

Для добавления отправь строку:

`<api_token> @channel_username`

### `Модераторы`

Позволяет:

- добавить модератора;
- удалить модератора.

Для добавления отправь numeric Telegram user id человека.

## Что теперь показывается по каналу

В карточках сообщений и контента панель старается показывать название или username канала, а не внутренний id editorial-записи.

То есть в интерфейсе модератора ты видишь канал в человекочитаемом виде.

## Рекомендуемый порядок работы

Самый простой сценарий:

1. Нажми `Обновить входящие`.
2. Открой `Поступившие сообщения`.
3. Быстро прими решения по новым сообщениям.
4. При необходимости проверь `Черновики на review`.
5. Если работаешь по слотам, запусти `scheduler`, потом `publisher`.

Если нужно посмотреть историю базы:

1. Открой `Все сообщения` для `submissions`.
2. Открой `Пасты` для библиотеки паст.

## Выгрузка статистики

В разделе `Дополнительные функции` есть кнопка `Выгрузка статистики`.

После нажатия бот:

- обновляет количество подписчиков через сабботов;
- сохраняет новый snapshot подписчиков;
- формирует Excel-файл;
- отправляет его в чат.

В таблице шесть колонок:

1. `Название канала`
2. `Тэг канала`
3. `Подписчики`
4. `Изменение за N дн.`
5. `Сообщений в предложку за N дн.`
6. `Необработанных сообщений`

`N` — выбранный пользователем период от 1 до 14 дней. Изменение подписчиков считается как текущий счетчик минус последний snapshot, который был не позже начала периода. Количество сообщений считается по времени их поступления в предложку; служебные копии из чата модерации не учитываются.

`Необработанных сообщений` — текущий остаток новых (`new`) и отложенных (`hold`) сообщений за всё время на момент выгрузки, независимо от выбранного периода. Обработанные сообщения и служебные копии из чата модерации в этот счётчик не входят.

## Статистика по администраторам

Главный администратор видит в `Дополнительных функциях` отдельную кнопку `Статистика по администраторам`. Бот запрашивает календарный месяц в формате `2026-08`, `08.2026` или слово `текущий` и присылает Excel-файл с двумя листами:

- `Сводка` — количество одобрений, отклонений и общее число уникально обработанных предложек по каждому администратору;
- `Детализация` — решение, дата, канал, ID и username автора, исходный текст и способ обработки каждой предложки.

Столбец `Сам себе` выделяет случаи, когда Telegram ID автора совпадает с ID администратора. Текст и данные автора сохраняются в реестре в момент модерации, поэтому удаление исходного сообщения из Telegram не убирает их из отчёта. Повторные нажатия не добавляют обработку, отменённые решения в месячную статистику не входят.
